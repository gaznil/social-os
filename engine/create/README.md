# Stage 3 — Create

Makes each calendar slot into a ready post.

**Writing:** the platform skill (`ig-reel`, `ig-caption`, `yt-script`, `linkedin-post-writer`, `x-post`…), always
finished by the platform humanizer (`ig-human`, `linkedin-humanizer`, `x-human`).
**Graphics:** carousels/posters designed as HTML and rendered to PNG (1080x1350 for Instagram), `ig-carousel` for copy.
**Video:** Motion King (made from nothing), Edit King (the user's footage), `yt-edit` / `yt-shorts` for cut lists.
**Filming** is the user's job; the draft says exactly what to shoot.

**Out:** a draft in the dashboard (text + media + target account + planned time), status `waiting approval`.
Media files stay on the PC or Drive, never in git.
