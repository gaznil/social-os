# Facebook (Pages)

**Skills:** no good dedicated pack exists (see `SKILLS.md`). Write with the Instagram pack (`ig-caption`,
`ig-carousel`, `ig-repurpose`) adapted for Facebook (longer text works, links are allowed), plus `copywriting`.
Always humanize with `ig-human`.

**Publish:** Composio `facebook` toolkit, posting to Pages the user admins. **Numbers:** `FACEBOOK_GET_POST_INSIGHTS`.

**Rules that bite**
- Posting works for Pages, not personal profiles.
- Never repost the Instagram post word for word on the same day; adapt it.
