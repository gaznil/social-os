# Social OS data shape

The dashboard and every `sos-*` skill read and write exactly these fields.


- `accounts/{accountId}`: `platform`, `label` (shown in the dashboard, no handle needed), `niche`, `language`, `postsPerWeek` (number), `composioAccountId` (string or null), `bestTimes` (array of `HH:MM` India time or absent, set by sos-results once 6+ posts are measured), `voiceProfile` (object|null, learned by `sos-learn`: `tone`, `manglishMix`, `commonPhrases` array, `bannedWords` array, `winningFormats` array, `updatedAt`), `status` (`setup` = added from the dashboard, Claude still has to make its private folder + Composio link | `active` | `paused`), `updatedAt` (ISO). Adding from the dashboard also writes a `messages` doc asking Claude to set it up.
- `posts/{postId}`: `accountId`, `platform`, `format` (`text`|`image`|`carousel`|`story`|`reel`|`video`|`short`|`thread`), `title` (YouTube only, else `""`), `caption`, `mediaUrls` (array of strings), `thumbnailUrl` (string|null, optional cover/thumbnail preview), `audioNote` (string|null, trending sound name to add manually in Instagram app), `shelfLife` (`update`|`trend`|`evergreen`, default `evergreen`), `expiresAt` (ISO|null, deadline for `update`/`trend` posts), `viewerScore` (number|null, 0-100 synthetic viewer panel score), `isTrialReel` (boolean|null, Instagram Trial Reel flag), `collabHandle` (string|null, optional collaborator tag reminder), `editedFrom` (string|null, original caption before user inline edit in Approve, for `sos-learn`), `feedbackNote` (string|null, user note when sent back to draft), `plannedAt` (ISO), `status` (`draft`|`waiting`|`approved`|`posting`|`posted`|`failed`|`rejected`), `approvedBy` (`dashboard`|`chat`|null), `approvedAt` (ISO|null), `postedAt` (ISO|null), `metrics` (object|null, set by sos-results: `views`, `reach`, `likes`, `comments`, `saves`, `shares`, `checkedAt`; missing = null), `platformPostId` (string|null), `permalink` (string|null), `error` (string|null), `problems` (array of strings from preflight), `updatedAt` (ISO).
- `messages/{messageId}`: `from` (`user`|`claude`), `text`, `status` (`new`|`done`), `reply` (string|null), `createdAt` (ISO).
- `ideas/{ideaId}`: `text`, `accountId` (string|null = any account), `source` (`user`|`research`|`plan`), `shelfLife` (`update`|`trend`|`evergreen`|null), `expiresAt` (ISO|null), `status` (`new`|`drafted`|`dropped`), `createdAt` (ISO).
- `jobs/{jobId}`: Studio requests (sos-studio). `accountId`, `kind` (`prompt` = a Prompt Guy video prompt | `pack` = prompt + one draft per active account), `brief` (string), `clipUrl` (string|null: a public link, or a file name in `C:\Gaznil\social-os-media\inbox\`), `model` (`haiku`|`sonnet`|`opus`|null = Claude picks), `effort` (`low`|`medium`|`high`|null), `status` (`requested` | `working` | `done` | `failed`), `prompt` (string|null, set by Claude), `postIds` (array, pack drafts), `note` (string|null, set by Claude), `createdAt`, `updatedAt`. Video = Prompt Guy only: no job ever runs a video tool.
- `schedules/{scheduleId}`: `accountId` (string|null = all accounts), `kind` (`research`|`publish`|`results`), `every` (`daily`|`weekly` = Mondays), `time` (`HH:MM` India time), `status` (`requested` = added in the page, Claude must create the cloud job | `active` | `paused` | `remove` = Claude deletes the cloud job, then the row), `cloudTaskId` (string|null, set by Claude), `note` (string|null, set by Claude), `createdAt`, `updatedAt`.
- `competitors/{autoId}`: profiles the user liked. `link` (profile URL or @handle), `platform`, `accountId` (string|null = best fit), `note` (string|null; user writes why they like it, Claude overwrites with what it learned), `source` "user", `status` (`new` = Claude adds it at the next research run | `tracked` | `remove`), `createdAt`.
- `stats/{accountId}-{YYYY-MM-DD}`: one per account per India day, written by sos-results. `accountId`, `date` (`YYYY-MM-DD`), `followers` (number|null), `views` (new views that day), `posts` (items posted that day). `pulledAt` (ISO, set by the dashboard Refresh button; the page shows "Updated N min ago" from it). Feeds the dashboard Growth section.
- `options/{optionId}` (v24-v26 Plan tab): `accountId`, `door` (`week`|`month`|`topic`|`video`|`slot`|`auto`), `title`, `storyFormat` (one of the 10 story formats), `format` (`reel`|`carousel`|...), `why` (one line), `what` (plain what-it-is), `hook`/`concept`/`needs` (optional, shown in the brief detail popup: opening line, 3-5 line idea, what to check first), `shelfLife` (`update`|`trend`|`evergreen`), `expiresAt` (ISO|null), `firstMover` (`untapped`|`early`|`saturated`|null), `postId` (string|null, when it fills a calendar slot), `status` (`new` = Claude wrote it | `picked` = user picked, Claude writes the script | `dropped`), `createdAt`, `updatedAt`.
- `scripts/{scriptId}`: `accountId`, `optionId` (string|null), `inspirationId` (string|null, when created from Reel Radar), `title`, `storyFormat`, `hookScore` (number|null, 0-100 from `hookscore.py`), `shelfLife` (`update`|`trend`|`evergreen`), `expiresAt` (ISO|null), `firstMover` (`untapped`|`early`|`saturated`|null), `en` (English script), `mlen` (Malayalam-English mix), `status` (`draft` = waiting for the user | `approved` = gate 1 passed, Claude makes every platform version | `changes` = rewrite using `note` | `done` = platform posts created, stays visible for filming/teleprompter), `postIds` (array of post ids created from this script), `note` (string|null), `lang` (`en`|`ml`, the version the user approved on), **structured script (v29, shown readable in the detail screen):** `format` (`reel`|`carousel`), `hookOptions` (top 3 `{text, score, formula, weakest}` scored by `ig-reel/hookscore.py`), `hook` (`{spoken, spokenMl, onScreen}`), reels: `beats` (`[{t, label, say, sayMl, show, onScreen}]`), carousels: `slides` (`[{n, headline, body, visual}]`), `cta`, `ctaMl`, `ctaOnScreen`, `caption`, `fillOnFilmDay` (array of what the user fills in; placeholders `{{like this}}` show as highlighted chips), `notes` (array: check before filming), `checks` (`{hookScore, seconds, slides, viral: [why it should work]}`). `en`/`mlen` stay as the full plain text (Teleprompter reads them in `[0-3s ON SCREEN: x]` + spoken-line form), `approvedAt`, `createdAt`, `updatedAt`.
- `inspirations/{inspirationId}` (v25-v26 Reel Radar): viral/trending URLs pasted by the user in the dashboard or VS Code chat, or discovered by `sos-research`. `accountId` (string|null), `url` (normalized URL, tracking params stripped), `platform` (`instagram`|`youtube`|`x`|`linkedin`|`threads`|`facebook`|`github`|`reddit`|`hackernews`|`web`), `userNote` (string|null), `title` (string|null, set by `sos-radar`), `hook` (string|null), `hookScore` (number|null, 0-100), `outlierMultiple` (number|null), `relatabilityScore` (number|null, 0-100), `firstMover` (`untapped`|`early`|`saturated`|null), `shelfLife` (`update`|`trend`|`evergreen`), `expiresAt` (ISO|null), `storyFormat` (string|null), `whyPopped` (string|null), `ourTwist` (string|null), `audioNote` (string|null), `score` (number|null, 0-100 from `tools/sos/radar.py`), `tier` (`P1`|`P2`|`P3`|`skip`|`expired`|null), `scriptId` (string|null), `status` (`new` = waiting for `sos-radar` | `scored` = ranked in Radar | `script` = user requested improved script | `scripted` = script ready in `scripts` | `skipped`), `createdAt`, `updatedAt`.
- `learnings/{learningId}` (v26 "What Claude learned"): `accountId` (string|null = all accounts), `category` (`voice`|`edits`|`hooks`|`topics`|`timing`), `text` (one concise rule Claude learned), `source` (string, e.g. `"Video #14 transcript"`, `"Caption edit on Claude Code post"`, `"4.2x Heater"`), `createdAt` (ISO). Deleting a doc from the dashboard removes that rule from future generation.
- `hooks/{hookId}` (Hook Vault): `template` ("Stop doing [X]. Start doing [Y]."), `example` (the real hook it came from), `type` (`swap`|`build`|`claim`|`list`|`contrarian`), `hits` (how many times it beat 2x the median), `source` (competitor/trend/ours), `accountId` (string|null), `createdAt`. Claude writes these; "Use this" saves an idea `HOOK: ...`.
- Messages with `kind` (v24): `week` | `month` | `topic` (Plan doors, `accountId` set) -> research + write `options`; `swap-own` | `swap-options` (calendar slot, `postId` set) -> fit the user's own content into that slot, or write new `options` with `door: "slot"`.
- `feedback/{autoId}` (v26 dashboard Feedback button): issues/ideas about the dashboard itself. `kind` (`bug`|`look`|`idea`), `text`, `tab` (page it was sent from), `accountId` (string|null), `device` (`phone`|`desktop`), `status` (`new` | `saved` = copied to `docs/dashboard-feedback.md` | `done` = fixed), `reply` (string|null, one line from Claude), `createdAt`.
- `briefs/{YYYY-MM-DD}` (Morning brief, Home top card): written by sos-research at the end of each daily run. `date`, `createdAt`, `summary` (one line), `sources` (array), `top` (max 3: `{ref: options|scripts|inspirations, id, accountId, title, format, score, shelfLife, expiresAt, firstMover, what, why}`; `what` = plain words: what the thing is and does), `learned` (0-2 short lines), `newHooks` (number). The card's buttons act on the `ref` doc (Pick/Skip an option, Write script/Skip an inspiration, Review a script).
- `runs/{runId}`: `kind` (`publish`|`inbox`|`research`|`analytics`), `startedAt`, `finishedAt`, `summary` (one plain sentence).
- `settings/main`: `timezone` (`Asia/Kolkata`), `postingWindows` (array, default `["09:00","13:00","19:00"]`).
