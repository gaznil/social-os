## 1. Daily auto-run (new)

- One schedule attached to the OS that runs **every day** by itself (Claude cloud scheduled task; at most once an hour allowed; uses normal subscription usage).
- Each run:
  1. Finds trends **everywhere**: GitHub trending (new repos, fast star growth, new releases of popular tools), Reddit, Hacker News, YouTube, X (free route NOT verified yet), Product Hunt / AI news, plus links the user dropped in Reel Radar, plus competitors and "profiles I like".
  2. Turns them into **topics**.
  3. Scores each topic on: **virality**, **relatability** (to the user's audience: Kerala/Malayalam, AI tools), **first-mover chance**, **shelf life** (section 3), effort to make, fits the account's niche.
  4. Writes **scripts** for the best ones (EN + Malayalam-English, in the user's voice from section 2).
  5. **Suggests posts**: puts them in the dashboard as options + draft scripts for the user to approve.
- **"I am the first person to post"**: for each topic, check whether creators in the niche (esp. Malayalam / Indian AI creators on IG + YouTube) already posted about it. Show a "first-mover" signal: e.g. *Nobody covered it yet* / *2 creators posted, still early* / *Already everywhere, skip or new angle*. Fresh + uncovered topics go to the top.
- Run summary goes to the `runs` collection (Engine Log) in one plain line.
- Open: what time of day the run happens (user to pick; suggest early morning IST so scripts are ready to film).

## 2. Self-learning on everything (new)

- For the main on-camera account first, then every account.
- Learns the user's **way of speaking, tone, voice** from:
  - videos the user posts (transcribe them: `tools/sos/deepdive.py` already does transcripts),
  - every edit the user makes (caption edits = `editedFrom`, script "Ask changes" notes, "Back to draft" notes = `feedbackNote`),
  - what the user rejects or drops.
- Learns **not only voice**: hooks that worked, topics that worked, formats, video length, Manglish mix (how much Malayalam vs English), words/phrases the user always uses or never uses, best posting times, what got views/saves (from results).
- Improves scripting every time from this. Every run reads the latest learnings first.
- Build on what exists: `sos-learn` + `LESSONS.md` (system lessons) and `private/accounts/<id>/voice.md` + `style.md` (per account).
- **Separate field in the dashboard to show the user what was learned**: e.g. a "What Claude learned" section per account:
  - Voice card (tone, common phrases, Manglish mix, sentence style),
  - list of learnings, each with: what, learned from (which video / edit / result), date,
  - user can remove a wrong learning.

## 3. Shelf life / expiry on ideas and Radar (new, from 21 Nov chat)

- Every Radar card and research idea gets a type:
  - **Evergreen** (tips, how-tos): never expires.
  - **Trend** (trending sound, meme, challenge): window ~3-14 days (NOT verified, research real trend lifespans first).
  - **Update / news** (new feature, tool launch): window ~1-3 days (NOT verified).
- Badge on the card: *Evergreen* / *Trend · N days left* / *Post by <day time>*.
- Past the window: card shows **Expired · avoid**, with buttons **Remake as evergreen** (keep the idea, drop the news angle) and **Skip**.
- A live trend/update outranks an evergreen P1 (evergreen can wait).
- The deadline follows the script into Approve + Calendar. Approving after expiry warns: "this trend expired N days ago, post anyway?"
- Open (user to answer): expired cards greyed and kept visible, or hidden automatically? Warning line on Home ("3 trend ideas expire today")?
